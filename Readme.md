# HandoverOS

Evidence-first AI project handover platform.

## Problem

Project context often gets lost when people leave or change roles.
Files remain, but the reasoning, decisions, unfinished work and risks
are harder to recover.

## MVP

HandoverOS converts project evidence into a structured handover
containing:

- Decisions
- Tasks
- Owners
- Risks
- Dependencies
- Blockers
- Open questions
- Conflicts
- Next actions
- Supporting evidence

## Tech Stack

- React
- Vite
- Tailwind CSS
- FastAPI
- Python
- Gemini API
- SQLite
